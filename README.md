Blinkit Sales Analysis – SQL
📌 Project Overview

This project focuses on analyzing Blinkit sales data using MySQL to uncover meaningful business insights related to product performance, outlet performance, item fat content, sales contribution, and customer ratings.

The project includes data cleaning, KPI analysis, aggregations, percentage calculations, and advanced SQL techniques such as window functions.

🎯 Business Objective

The main objective of this project is to analyze Blinkit's sales data and answer key business questions such as:

What is the overall sales performance?
Which item fat content generates the highest sales?
Which item types perform best?
Which outlet locations generate the most revenue?
How does outlet size contribute to total sales?
How do sales vary by outlet establishment year?
Which outlet location type has the highest average sales and rating?

🧹 Data Cleaning

The dataset contained inconsistent values in the Item Fat Content column.

For example:

LF
low fat
reg

These values were standardized into:

Low Fat
Regular

Example:

UPDATE blinkit
SET item_fat_content =
CASE
    WHEN item_fat_content IN ('LF', 'low fat') THEN 'Low Fat'
    WHEN item_fat_content = 'reg' THEN 'Regular'
    ELSE item_fat_content
END;
